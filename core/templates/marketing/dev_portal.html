Autenticación

La API usa JWT (Bearer Token). Obtén tu token autenticándote con tu usuario y contraseña.

POST /api/auth/jwt/obtain/ 
# Obtener token JWT
curl -X POST https://travelhub.cc/api/auth/jwt/obtain/ \
  -H "Content-Type: application/json" \
  -d '{"username": "agencia@ejemplo.com", "password": "tu_password"}'
Usar el token en cada request
curl -H "Authorization: Bearer eyJhbGciOi..." \
  https://travelhub.cc/api/ventas/

Endpoints Principales

GET /api/ventas/ Listar ventas

Parámetros: ?page=1&page_size=25&estado=CONFIRMADA

[
  {"id": 1, "numero": "V-2026-0001", "cliente": "Juan Pérez",
   "total_venta": "850.00", "estado": "CONFIRMADA"}
]
POST /api/boletos/importar/ Importar boleto

Acepta texto plano o PDF de KIU, Sabre, Amadeus y Travelport.

curl -X POST https://travelhub.cc/api/boletos/importar/ \
  -H "Authorization: Bearer TOKEN" \
  -F "archivo=@ticket.pdf"
POST /api/facturas/emitir/ Emitir factura VEN-NIF

Genera factura electrónica venezolana con IVA, IGTF y retenciones ISLR. Corporativo y consumidor final.

GET /api/tasas/bcv/ Tasas BCV

Tasas de cambio oficiales del Banco Central de Venezuela (EUR, CNY, TRY, RUB).

Webhooks

Recibe notificaciones en tiempo real cuando ocurren eventos en tu agencia. Configura las URLs desde el panel de administración.

Evento Disparador
venta.creadaNueva venta creada
pago.confirmadoPago confirmado
boleto.importadoBoleto importado

Payload de ejemplo

{
  "event": "venta.creada",
  "timestamp": "2026-07-20T12:00:00Z",
  "agencia_id": 1,
  "data": {
    "venta_id": 42,
    "total": "850.00",
    "cliente": "Juan Pérez"
  }
}

Los webhooks se firman con HMAC-SHA256. Valida la firma en la cabecera X-Webhook-Signature.
